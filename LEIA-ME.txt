SNAKE ODYSSEY — CENTRAL DE DOWNLOADS

O site NÃO precisa ser recriado a cada versão.

O QUE VOCÊ PRECISA FAZER (UMA VEZ):
1. Criar ou escolher um repositório PÚBLICO no GitHub para distribuir o jogo.
2. Abrir config.js e preencher owner (seu usuário ou organização) e repo (nome do repositório).
3. Publicar a pasta inteira deste site no Netlify Drop: https://app.netlify.com/drop
   Dica: conecte o repositório do SITE ao Netlify para atualizações futuras de layout automáticas.

A CADA NOVA VERSÃO DO JOGO:
1. GitHub > repositório do jogo > Releases > Draft a new release.
2. Criar uma tag como v1.0.5 e anexar os arquivos correspondentes:
   Android: SnakeOdyssey-v1.0.5-android.apk
   Windows: SnakeOdyssey-v1.0.5-windows.exe OU .zip
3. Escrever as novidades e clicar em Publish release.
4. O site exibirá automaticamente a versão mais recente e as anteriores, sem alterar o HTML.

ATENÇÃO:
- Ainda NÃO há APK ou executável neste pacote.
- O GitHub Releases precisa estar público para a consulta sem login.
- O site consulta até 100 releases mais recentes. Para jogos com muitos lançamentos, adicione paginação no futuro.
- Para PC, .zip, .exe, .msi ou .msix são aceitos. Arquivos ZIP Android devem conter 'android' ou 'mobile' no nome para não aparecerem na lista de PC.
- Se você publicar uma release com dois arquivos PC, ambos aparecerão no histórico.
- Atualizar o APK no site NÃO atualiza automaticamente apps já instalados no Android.
- Para manter um endereço estável no Netlify, atualize sempre o MESMO projeto/site.
- Releases marcadas como pre-release ficam ocultas por padrão; altere includePrereleases no config.js para exibi-las.
