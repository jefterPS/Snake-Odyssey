ATUALIZAR O SITE NO GITHUB
1. Abra https://github.com/jefterPS/Snake-Odyssey
2. Clique em Add file / Upload files.
3. Envie index.html, app.js, config.js e a pasta assets com icone.png.
4. Confirme as alterações, substituindo arquivos antigos.
5. Aguarde GitHub Pages publicar.

PUBLICAR UMA VERSÃO DO JOGO
1. No repositório, abra Releases > Draft a new release.
2. Crie uma tag (ex.: v1.0.0) e anexe SnakeOdyssey-v1.0.0.apk e/ou SnakeOdyssey-v1.0.0-Windows.zip.
3. Publique a release. Ao recarregar o site, a versão aparecerá na plataforma correspondente.

IMPORTANTE: este site apenas distribui os arquivos. Não atualiza automaticamente apps já instalados.
